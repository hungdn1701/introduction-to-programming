Cint play_by_halving(int secret)
{
    int low = 1, high = MAX_NUMBER, guesses = 0;
    for (;;) {
        int guess = low + (high - low) / 2;
        guesses++;
        if (guess == secret)
            return guesses;
        if (guess < secret) low = guess + 1;
        else high = guess - 1;
    }
}

    Slide 7. guess2.c: truyền số bí mật qua tham số, máy tự chơi thử 100 ván

    • Không biến toàn cục: số bí mật là **tham số** — gọi được với mọi số để kiểm thử
    src/guess2.c
    int play_by_halving(int secret)
{
    int low = 1, high = MAX_NUMBER, guesses = 0;
    for (;;) {
        int guess = low + (high - low) / 2;
        guesses++;
        if (guess == secret)
            return guesses;
        if (guess < secret) low = guess + 1;
        else high = guess - 1;
    }
}

    Bản guess2.c của King bỏ biến toàn cục: số bí mật được truyền qua tham số. Mình thêm hàm play_by_halving chơi theo cách chia đôi, nhận số bí mật làm tham số và trả về số lượt.
